
# Community Health Outreach Monitoring

A practice project in Python (pandas) for Monitoring, Evaluation and Learning (MEL).
Data is fictional and created for learning.

## Questions answered
- Attendance vs target for each event
- Overall attendance rate (from totals, not the mean of percentages)
- Attendance and follow-up rates by county
- Events with the lowest follow-up rates
- Three evidence-based recommendations

## Key findings
- Overall attendance rate: 95.7%
- Overall follow-up rate: 83.6%
- Follow-up was weakest in Kajiado and Machakos

## Tools
Python, pandas, numpy

## Files
- project_1_health_outreach.py: analysis code
- summary.csv: county summary table
